Projects

Email Project

TMyWindowsService is a C# Windows background service that continuously monitors a website's availability and status. Built on the .NET Worker Service template, it runs silently in the background, checking the site at regular intervals and integrating with the Windows Service Control Manager for reliable start, stop, and shutdown handling. It also monitors the health of its corresponding database, and if the site goes down or the database becomes unavailable, it automatically sends an email alert to the manager.

Office Mapper

A SQL Server–backed tool built to solve a practical business problem: finding employees near a given office location. The system stores structured data on people, offices, and skills, then uses a haversine-distance query to return all employees within a specified radius of any office. Useful for staffing, regional coverage, or logistics planning. Built using C# and SQL (SSMS).

Colossal Caves

Colossal Caves is a C#, object-oriented reimplementation of the classic Colossal Cave Adventure text game. It uses a reflection-based architecture that auto-discovers game objects (items, commands, locations, connections) into singleton dictionaries, so everything in the world is a single instance rather than freely instantiated objects. It's actively developed, with systems like combat/enemies, player death, a plant-growth puzzle, a debug/god-mode toolset, and polished console output already in place.
